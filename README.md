# Mhideh Enterprises — Bespoke Gift Studio & Online Catalog

Official e-commerce product catalog and **Order via WhatsApp** storefront for **Mhideh Enterprises (mhide online store)**, based in Ringroad, Ibadan, Nigeria with nationwide delivery.

## ✨ Features

- **Warm Luxury Gift Theme:** Styled with a custom Gold (`#D4AF37`), Cream (`#FDFBF7`), Deep Charcoal (`#141311`), and Royal Burgundy (`#6B1323`) palette with *Playfair Display* & *Plus Jakarta Sans* typography.
- **6 Curated Gift Categories:**
  - Custom Frames & Wall Clocks
  - Custom Wears & Apparel (Birthday/Couple T-Shirts, Embroidered Hoodies, Satin Robes, 3D Caps)
  - Throw Pillows & Towels
  - Customized Cufflinks & Gift Sets
  - Picture / Magic Mugs & Stickers
  - Banners & Event Prints
- **Interactive Personalization Modal:** Customers can select sizes/variants, choose colors, and enter custom engraving/print notes before adding items to their Gift Bag.
- **"Order via WhatsApp" Checkout Drawer:** Automatically formats an itemized order summary (with custom notes, delivery method, customer name, and location) and opens a pre-filled WhatsApp chat to `+234 810 791 8675`.
- **VIP Bespoke Gift & Bulk Souvenir Concierge:** Interactive quote builder for weddings, birthdays, anniversaries, and corporate orders.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Customizing Products

Edit [`src/data/products.ts`](./src/data/products.ts) to update product prices, images, options, or WhatsApp contact details.
